═══════════════════════════════════════════════════════════════════════════════
                           QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════════

RPC Methods (call via POST /agents/TravelAgent/{userId}/rpc):
  • getState() → current state, trip info, messages
  • prepareTurn(message) → classify intent, detect new trip
  • handleMessage(message) → traditional single-pass pipeline
  • thinkChat(message) → multi-turn reasoning with tools
  • startNewTrip() → create new thread
  • loadTrip(tripId) → switch to saved trip
  • appendConversation(user, assistant) → persist messages

Tools Available (registered by thinkChat):
  • search_flights - search flights via Amadeus
  • search_hotels - search hotels via Amadeus
  • search_activities - search activities via Amadeus
  • search_destination_info - RAG via Vectorize

Architecture Flows:
  Traditional: keyword detection → RAG/tools parallel → LLM
  Think: register tools → LLM reasons → tools execute → reflect → response
